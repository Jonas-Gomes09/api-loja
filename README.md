# API-Loja

Esta API é feita somente para fim de testes e não é um produto real, há inclusive funções ainda não implementadas.

O código, a logo e a empresa do website foram criados por mim. A empresa no website é totalmente fictícia.

### Módulos instalados:
- Express (e @types/express)
- Typescript (e @types/typescript)
- TSC
- EJS (e @types/ejs)
- PATH
- ts-node-dev

### Dependências
- NodeJS

### Execução

Para executar o servidor digite "npm test" ou "ts-node-dev src/server.ts" no terminal na pasta do servidor (api-loja)
